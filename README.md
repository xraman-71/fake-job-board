# 🐍 Fake Python Job Board - Extended

---

A modern, fully-featured job board application with 200+ fake Python and tech positions across multiple locations. Built with vanilla JavaScript and Bulma CSS framework.

## ✨ Features

- **200+ Job Listings**: Extended dataset with positions across 50+ locations
- **Advanced Search**: Real-time search by title, company, or location
- **Smart Filtering**: Filter by job category (Python, Developer, Engineer)
- **Location Filter**: Browse jobs by specific cities
- **Sorting Options**: Sort by newest, company name, or job title
- **Pagination**: Smooth pagination for browsing large datasets
- **Location Summary**: Visual grid showing job distribution by city
- **Interactive Job Cards**: Click any job to view detailed modal
- **Responsive Design**: Adapts to different screen sizes
- **Modern UI**: Glassmorphism effects, gradients, and smooth animations

## 🚀 Quick Start

1. Download or clone the repository
2. Open `index.html` in your browser
3. Use search and filters to find positions
4. Click any job card for details

## 🔍 Search & Filter

| Feature | Implementation |
|---------|---------------|
| Search | Debounced real-time input (300ms) |
| Location | Dropdown filter with all cities |
| Category | Toggle buttons for quick filtering |
| Sort | Newest first, alphabetical options |

## 📊 Data Structure

Each job entry includes:
- `id`: Unique identifier
- `title`: Job position name
- `company`: Employer organization
- `location`: City and state code
- `date`: Publication date
- `category`: Job classification
- `url`: External application link
